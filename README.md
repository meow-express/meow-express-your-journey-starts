### 📖 這是什麼？

這是一個可以互動的線上漂流本。

細咪在日本文具店、手帳紙膠帶和咖啡香裡，開始了一場6站的漂流。你可以在線上：

- **聽歌**：兩首原創漂流歌
- **集章**：每到一站蓋上喵星郵戳，集滿 6/6
- **填色**：拿到線稿，在填色工房自由上色
- **寄明信片**：做一張你的明信片，寄給下一位

原本的模樣，乾淨，沒有多餘的指令文字。

### 🗺️ 漂流路線

`首頁 → 旅程 → 音樂館 → 參觀故事 → 取得線稿 → 填色 → 製作明信片 → 寄給下一位`

### 🎵 喵星音樂館

| 歌名 | 場景 | 試聽 |
| :--- | :--- | :--- |
| **小包裹 Xiao Bao Guo 3** | 文具店裡的午後 | [去 Suno 聽原曲 ↗](https://suno.com/s/F0NFje8b8sRaJsG0) |
| **喵務員與水玉的跨頁旅行** | 阿爾卑斯到托斯卡尼 | [去 Suno 聽原曲 ↗](https://suno.com/s/GHreDWAJ7DBxNeuT) |

> 音樂使用 Suno 永久連結，不會失效。點卡帶上的按鈕外跳就能聽。

### ✏️ 怎麼玩？

1. 打開上面的體驗連結
2. 跟著 6 站慢慢逛，聽聽歌，集個章
3. 在 **填色工房** 下載線稿，上色後上傳
4. 在 **明信片工房** 製作你的明信片，下載圖片
5. 把 QR 碼印出來，貼在你的實體手帳最後一頁，下一位掃碼就能繼續漂
